# 原生会话与 Web 边界

当前 Web 不支持账号登录，账号页不提供用户名密码字段，也不请求 NAS 登录接口。
不引入本地代理绕过 CORS，不将 NAS SID / SynoToken 放入浏览器存储。访客功能保持可用。
对当前 NAS API 的只读 Origin 探测没有得到允许本机 Web origin 的 CORS 响应头；此检查不是浏览器端登录验收。

Android / Windows 复用应用原生网络客户端，遵循现有 Windows 代理策略与 TLS 验证。
NAS SID 与 SynoToken 使用系统安全存储，Android 禁止凭据备份，不降级为明文偏好。
偏好中只有公开连接信息和退出标记。登录成功、恢复和返回前台都查询 NAS 验证 UID。
取消 / 超时使旧请求失效；能取得 SID 的迟到登录结果会尝试撤销，不替换新身份。
离线退出先移除本机身份，并持久化退出标记；只保留加密会话用于再次联网后的撤销。
恢复和再次登录必须先处理待撤销会话；安全存储清理失败时显示可重试错误。

这种方案不提供服务器端应用会话隔离、独立权限或全设备撤销能力。
对查询 URI 的日志管理、NAS 会话期限与账号权限仍需遵循 DSM 的运行环境。
详细限制见 [直连登录](identity-integration.md)。
