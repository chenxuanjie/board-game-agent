# Web 与原生会话边界

Web 使用 `__Host-bga_synology`：Secure、HttpOnly、SameSite=Lax、Path=/、无 Domain。
浏览器不收到原生令牌或 NAS SID。POST 同时验证 Origin 和随机 CSRF；服务禁用跨域 CORS。
原生使用 `X-Identity-Client: native-v1` 和随机应用 Bearer；带 Origin/Sec-Fetch-Site/Cookie 的请求不能冒充原生。
两种会话不能混用。原生令牌由系统安全存储保存，Android 禁止备份，不降级为明文偏好。

客户端公开用户缓存只用于离线显示，不是登录证明。登录成功后再次查询服务，服务每次恢复都用 NAS UID 验证。
取消/超时/会话切换使旧请求失效；候选登录验证失败时撤销会话。请求和存储均有等待上限。
离线退出先清除身份并持久化退出标记，仅保留加密原生令牌用于补偿退出；恢复前先补偿，不能恢复旧身份。
本机清理失败会阻止再次登录，显示可重试错误，不吞掉失败。

服务的会话密文使用 AES-256-GCM 和版本/行 ID 附加验证数据。会话到期和退出进入持久化撤销队列。
从数据库泄露的令牌哈希不能直接作为客户端令牌使用；数据库、密钥和反向代理仍需独立保护。
此设计减少凭据暴露，但不宣称完整安全认证或多副本/全设备撤销能力。
