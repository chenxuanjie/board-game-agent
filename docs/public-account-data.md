# 同一 NAS 的公共账号数据

Windows/Android 使用已有群晖 FileStation，不新增 NAS 服务。Web 保持访客模式。知识库仍要求登录。

## 管理员一次性配置

1. 在当前知识库共享文件夹下创建 `apps/board_game_agent/public/v1`，例如 `/friend/apps/board_game_agent/public/v1`。
2. 参与账号需 FileStation 使用权。启用用户 home 服务以保存私人同步日志。
3. 公共根目录对参与组允许读取/列举、遍历和创建子文件夹；不能授权普通用户修改/删除其他人的已有文件。
4. 设置继承 ACL：参与组对下面的文件夹/文件只读；创建者（CREATOR OWNER）对自己的文件夹和文件有读写权。管理员保留管理权；普通用户不得改权限或取得他人所有权。
5. 用两个普通账号验收：A 创建自己的 UID 目录和快照，B 可读；B 修改、删除 A 的文件必须被 NAS 拒绝。A 仍能覆盖自己的快照。管理员身份不能代替该项验收。

应用仅在公共根存在后创建自己的 UID 子目录；根缺失或权限不正确时显示错误并保留本机数据。文件所有者由 DSM 返回，不能通过编辑文档中的账号名认领票数。服务端 ACL 是最终边界，客户端路径限制不能代替 ACL。

参考：[FileStation 官方 API](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Package/FileStation/All/enu/Synology_File_Station_API_Guide.pdf)，使用 Info 的 uid/is_manager、List 的 owner/perm，以及 Upload、Download；复用现有 http、代理、认证、超时和取消，没有新增依赖或后台服务。

## 数据与迁移

| 范围 | 内容 |
| --- | --- |
| 私人 | 收藏、想玩、专题清单、搜索历史、最近浏览、每日推荐、AI 对话、昵称和既有个人偏好 |
| 公开 | 收藏/想玩的桌游 slug、操作版本、取消标记、UID、设备 ID |
| 仅设备 | 登录缓存、凭据、API Key、通知、资料更新状态、下载缓存、语言和主题 |

公共文件为 `/<共享目录>/apps/board_game_agent/public/v1/u<DSM UID>/d<设备 ID>.json`，每设备覆盖自己的快照，写后读回校验，相同快照不重复上传。私人数据仍在自己的 home 下采用不可变增量日志。

一个 UID 每款游戏最多各贡献一次收藏和想玩。公共汇总排除自己的 UID，再叠加本机已保存选择。取消标记不会因旧设备回传而丢失；离线并发按逻辑时钟与操作 ID 确定性合并，不依赖系统时间。公共导入不推进私有游标，避免跳过 AI 对话等其他操作。

暂停“账号云同步”仅暂停私人 home 传输，公开的收藏/投票继续同步，界面分别显示状态。访客数据不自动复制给账号；旧匿名安装实例票数无法可信映射到 UID，旧目录保留但不再读写，不能混入新人数。当前账号已有本机选择会加入账号日志。

新增私人实体与旧客户端不兼容；参与设备须统一更新。未知实体会停止同步并保留数据，不无声丢弃。个人清单仍各账号独立，没有新增公共协同编辑、评论或云分享链接。

## 有界行为、验证与回退

公共快照每文件最多 512 KiB、8192 个操作；最多 1000 个账号、每账号 128 个设备、总体 2000 个快照。公共检查在 20 秒内完成或取消；前台每分钟补拉，修改稳定约 4 秒后同步，可手动刷新。没有实时推送，其他账号的变更在下次成功同步时可见。

任一快照错误、读取不完整或权限失败均保留上次完整统计，不把失败变成零人数。请求绑定登录 UID 和认证代次，退出/切换取消旧请求，旧适配器不能借新账号会话读写。

账号去重、跨设备恢复、取消、私有游标、离线/权限/身份/格式错误、迟到取消及业务投影有自动测试。真实公共 ACL 和 Android 实机尚未验收；编译及模拟测试不能代替这两项。面向同一 NAS 内的可信用户组，管理员有管理权，无端到端加密或互联网反作弊服务。

回退需同时回退主工程与共享 app_identity 包；云端快照和本机收藏保留，不删除资料。旧客户端不能配套新增公共接口，也不能忽略未知私人实体继续同步。

共享认证包版本：app_identity 0.4.0，提交以共享包仓库实际 HEAD 为准；主项目 pubspec.lock 固定该路径包版本。
