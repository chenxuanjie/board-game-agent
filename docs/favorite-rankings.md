# 喜欢排行榜

排行榜已经实现，但不在桌面侧栏、首页、App 底栏或“我的”页面增加入口。内部命名路由为 `/rankings`；桌面工作区也支持 `initialPage: 'rankings'`。页面共用真实游戏目录，点选条目进入详情，返回后仍在排行榜。

## 排名与数据范围

- 只按喜欢总数降序排列，不使用评分、评分人数或国庆想玩投票。
- 相同喜欢数并列，采用 `1、1、3` 的名次；同数时按名称、slug 稳定显示。
- 不展示零喜欢或当前目录中不可用的游戏，不填充示例总数。
- 未使用 WebDAV 时，单台设备对一个游戏最多贡献一次喜欢。取消喜欢减回一次。
- 使用 WebDAV 时，汇总同一资料空间中的各安装实例；重复同步覆盖同一记录，不重复增加。已有收藏在启动后也会同步，后续收藏变化和排行榜刷新继续更新统计。
- 离线保留其他设备最后一次成功读取的总数，并叠加本机最新已保存收藏。切换 WebDAV 地址或账号时，统计缓存隔离；不把旧空间的数据算到新空间。

目前没有账号统计服务，**这些是同一 WebDAV 内按设备安装实例计数的喜欢记录，不是全站去重用户人数**。重新安装、清空应用数据后会生成新安装标识，旧安装记录仍可能留在 WebDAV 中；不能据此宣称账号去重。其他设备的变化在下一次成功同步时可见，不提供实时推送。

## 存储与失败处理

本机收藏仍以 `favorite_games_v1` 为唯一业务来源，保留原有时间戳。统计只读取已完成持久化的收藏；乐观显示、失败保存或损坏的收藏源不能发布为新的远端快照。损坏数据保留，并提供重试，不作为空集合覆盖远端。

统计复用现有 `GameVoteService`、`GameVoteBallot` 和共享 WebDAV 客户端，增加独立命名空间和可注入的收藏源、缓存读写，不创建第二套网络或重试实现。

| 数据 | 位置 |
| --- | --- |
| 本机收藏 | `favorite_games_v1` |
| 喜欢统计缓存及安装标识 | `game_favorite_ranking_v1` |
| 喜欢记录 | `apps/board_game_agent/votes/game-favorites-v1/<deviceId>.json` |
| 国庆想玩投票 | 原有 `apps/board_game_agent/votes/national-day-2026/`，保持独立 |

文件协议沿用版本 1，`campaign` 字段用于命名空间；只接收当前命名空间、合法 slug 和安装标识。上传自身快照后，下载其他安装记录，按安装标识去重，远端缓存不包含本机贡献。身份创建、快照和总数都需先保存成功；保存失败时不伪造成功状态。

沿用每次请求 6 秒、一次同步 25 秒的超时，最多两次自动重试（3 秒、10 秒）。读取并发上限 8，最多 1000 个设备文件；每个喜欢快照最多 2048 个游戏、512 KiB，汇总最多 32768 个不同游戏。读取不完整、非法文件或超过上限时保留上次完整缓存，并允许重试。配置内容和凭据不写入排名文件。

## 实现位置与验收

- 排名规则：`lib/features/games/services/game_favorite_ranker.dart`。
- 收藏与统计衔接：`lib/app/state/app_controller/rankings.dart` 及原有 `collections.dart`。
- 共用页面：`lib/ui/shared/game_ranking_screen.dart`。
- 数据与页面测试：`test/game_ranking_test.dart`；原国庆投票回归：`test/game_vote_service_test.dart`。

测试覆盖并列与排序、已有收藏迁移、重复同步、取消喜欢、离线缓存、存储失败、读取损坏、同步期间修改、账号切换、投票隔离、WebDAV 目录，以及窄/宽布局、文本放大、错误重试和详情往返。网络验证使用模拟 WebDAV，不接触真实凭据或服务器；未构建安装包或执行真机网络验收。按用户要求不生成渲染图或截图。

回滚时移除隐藏路由及收藏统计挂接即可；不需要清空收藏，也不应删除原国庆投票。喜欢统计文件保留不会影响旧版本。
