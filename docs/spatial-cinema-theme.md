## 第一阶段范围

用户要求从本地 `tmp/test-demo-v5ui/netflix_spatial_from_ai/lib/main.dart` 的 Flutter 界面还原更大范围的展示结构，而非在旧桌面页上换颜色。该文件是参考来源，不是生产依赖；其展示原语已适配到 `lib/ui/shared/spatial/`。使用自己的应用名称，保留现有真实业务模型与账号边界。

本轮实现独立主工作区与首页：

- Web/紧凑端是静态桌游场景中的悬浮玻璃窗口；Windows 桌面直接显示铺满可用窗口的实体面板，不绘制外围场景、浮窗留白、阴影或独立电量胶囊。两种外壳共用内部导航和内容，均未使用 `DesktopWorkspace` 或 `CinemaHomeContent` 拼接首页。背景复用已有 `assets/mobile/mine/header_background_card.jpg`，不随选游或鼠标移动切换。
- 主卡使用原首页三个 banner，沿用桌游库、专题、AI 的点击目标和 7 秒轮播；悬停、路由不活跃或减少动画时暂停轮播。原图片的 1.04 倍裁边沿用原首页处理。
- 右侧保留参考的 Night Agent / Wednesday 电影示例。它们尚未替换为桌游推荐，不接电影服务或媒体播放；点击只改变本地示例选中说明。网络示例图片失败时用参考渐变回退。
- 下排使用基于当前账号收藏类型的十款推荐，展示真实封面、分类和评分，点击进入真实详情。首屏保持参考的 6/4/2 张完整卡片，取消横向滚动，右侧箭头进入独立推荐页展示全部十款；搜索仍匹配完整目录的名称、副标题和分类。算法与状态边界见 [收藏偏好推荐](personal-game-recommendations.md)。
- 删除底部播放器，没有补一个虚构的桌游播放器。恢复原宽屏上下边距 26/80；下排海报按原 Web 基准 141:216 控制比例，不随桌面剩余高度拉伸。小高度时仍受可用空间约束。右上胶囊按参考保留纯装饰电池图形，不读取或声称设备电量，排除其辅助功能语义。
- 侧栏使用参考的材质、分组和紧凑菜单样式，入口映射为现有桌游功能。窄屏使用可滚动菜单面板，保留设置和返回入口。

## Windows 实体窗口与圆角表面

桌面窗口就是实体面板，无场景背景或外围留白。`core/platform/native_window_surface.dart` 复用已安装的 `window_manager 0.5.2`，开启无边框和透明背景后，由 Flutter 对完整客户区绘制 32 dp 抗锯齿圆角表面。没有新增窗口依赖，也不把 Web 浮窗放进桌面背景。

- 移除 `CreateRoundRectRgn` / `SetWindowRgn`、DWM 圆角请求及自定义 runner 轮廓通道。Windows 10/11 使用同一表面绘制路径，不再按系统版本硬裁切。
- 透明边缘由真实 alpha 与抗锯齿覆盖绘制，不涂白色补角；窗口不添加可见外边距。无边框模式消除“隐藏标题栏”仍保留的系统非客户区边框。
- 最大化、全屏和贴靠使用矩形，恢复普通窗口后恢复圆角；切回其他主题恢复原隐藏标题栏。原生调用串行、过时请求合并，状态查询有超时与过期结果隔离；插件调用失败保留矩形界面，不启用裁切替代。
- `DesktopWindowFrame` 只绘制一份全窗渐变，标题栏透明；`SpatialGlass(embedded: true)` 和桌面侧栏不重新绘制背景，主工作区 Scaffold 透明。Web 保留参考的独立玻璃渐变和场景。
- 空间影院在面板顶部使用 48 dp 同材质操作区；最小化、最大化/还原、关闭为 38×30 dp 圆角 8 控件，浅色图标与悬停/焦点反馈。保留顶部拖动、双击最大化和 6 dp 边缘缩放，其他主题仍保留原窗口栏。
- Web/Android 只控制应用内的悬浮面板，不能改变浏览器或系统窗口轮廓。

复用来源：`window_manager 0.5.2` 的 `windows/window_manager.cpp::SetBackgroundColor/SetAsFrameless` 及 `window_manager_plugin.cpp::WM_NCCALCSIZE`，沿用原依赖和许可证，不复制插件代码。透明背景使用插件现有的 Windows 合成接口；插件没有返回底层合成 API 的真实成功值，调用成功不能单独证明显卡/远程桌面环境正确支持 alpha。组件测试验证透明像素和平滑边缘、状态及颜色接缝；**EXE 的合成效果、系统阴影、透明四角点击、DPI/持续缩放与贴靠仍待重建后实机验收**，不能标为完成。Windows 11 的系统圆角与这种客户区自绘圆角不是同一机制，见 [DWM 圆角限制](https://learn.microsoft.com/windows/apps/desktop/modernize/ui/apply-rounded-corners)。

## 2026-10-18 宽屏业务适配

右上角使用共用头像菜单，合并原独立铃铛。未登录显示访客及登录入口；登录后显示昵称、已登录/离线状态、账户管理及分隔后的退出登录。通知显示真实未读数，打开现有通知列表后标记已读，资料和 AI 通知继续进入对应业务。登录表单、退出与账号数据边界复用 AccountService；进行中的账号操作禁用重复登录/退出，失败保留真实错误，不伪造成功。账户变化关闭旧菜单，退出动画结束后才执行导航，支持 Escape、键盘选择、外部点击与快速重复操作。

账号菜单验证：账户、桌面工作区、手机首页和响应式共 189 项回归通过，另有 10 项账号菜单专项（含两种尺寸真实字体渲染）通过；静态检查通过。未构建或部署 Web、Windows、Android、Docker，NAS 仍使用此前镜像。

空间影院仍是独立外壳。可用工作区宽度达到 760 dp 时，业务页使用桌面内容；低于该断点保留紧凑页面。判断依据是实际窗口约束，不使用设备名或伪造 MediaQuery 放大手机页面。DesktopMetricsScope 使用内层内容区尺寸，避免 Web 外围场景的宽度放大浮窗内控件。

| 业务 | 宽屏呈现 |
| --- | --- |
| 桌游库、我的喜欢、最近浏览 | 共享 DesktopGamesPane 的分类、排序、筛选和 LibraryViewport，使用空间影院海报；190 dp 为列宽参考，完整列自适应，铺满内容宽度，不保留手机 620 dp 限宽或重复品牌/搜索头。收藏和最近浏览各自保留筛选状态。 |

| AI 助手 | DesktopAssistantPane 的桌面工具栏、消息区和输入区，较窄内容区由组件自身折行；AI 配置跳转使用桌面设置。 |
| 资料下载 | DesktopLibraryPane 的资源列表、筛选和操作，不再包裹手机资料页。 |
| 桌游专题 | DesktopNationalDayPage 的宽屏构图，数据与移动端共用。 |

侧栏搜索接入真实桌游库查询，进入库或窗口跨断点时恢复查询；分类、排序和游戏锚点使用既有浏览状态。桌面滚动控制器按页保留，详情往返不清空库筛选。海报仍使用真实封面和点击入口，首页参考构图、下排比例、电影示例和背景不变。桌面语义颜色适配同时覆盖空间影院，避免暗底工具栏继续使用暖木主题的棕色文字。

这些是已有桌面内容与独立影院外壳的组合，不宣称把原电影原型的每个业务页全部重新设计。原型右侧电影内容的正式桌游替代仍待用户确定。仅代码、测试和 Git 提交；既有交付镜像 5.0.0+39 不含本轮界面修改，须下次构建后部署。
