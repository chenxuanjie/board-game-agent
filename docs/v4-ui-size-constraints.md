# V4 桌面首页尺寸约束

本文记录 V4 Windows 桌面端首页在标准窗口下的尺寸基线，供后续布局调整与回归检查使用。

- 下列数值均为 Flutter 逻辑像素（dp）；Windows 实际屏幕像素会受系统显示缩放影响。
- 标准参考窗口为居中的 `1280 × 800`。依赖可用宽度计算的尺寸仅适用于此参考布局，不应当作所有窗口尺寸下的固定值。
- 调整相关布局时，应同步更新本文及对应的回归测试。

## 尺寸基线

| 区域 | 默认尺寸与布局 | 实现依据 |
| --- | --- | --- |
| 启动窗口 | `1280 × 800`，居中、普通窗口启动；最小尺寸 `1100 × 700`。 | `lib/main.dart:80–81` |
| 窗口控制与拖动 | 隐藏系统标题栏，使用应用自绘最小化、最大化/还原、关闭按钮；每个 `32 × 20`，合计 `96 × 20`，贴在右上角。顶部 `18` dp 高的区域用于拖动/双击最大化；窗口边缘 `6` dp 用于调整大小。按钮与拖动区叠加在应用顶部，不额外增加窗口高度。 | `lib/ui/v4/v4_window_controls.dart:127–128`；`lib/ui/v4/v4_workspace.dart:152–160` |
| 应用顶部工具栏 | 高 `78`；内边距左/右 `18`、上 `20`、下 `10`。搜索框高 `40`、最大宽 `680`；头像 `44 × 44`。 | `lib/ui/v4/v4_workspace.dart:323–344,402–403` |
| 左侧栏 | 桌面默认宽 `205`、占满窗口高度；顶部留白 `24`；Logo 盒子 `77 × 72`；导航项高 `44`、项间距 `3`。导航图标盒为 `24 × 24`，与文字间距 `10`。窗口内容宽度 `<1200` 时切换为宽 `76` 的图标栏；宽度 `<760` 时改为抽屉导航，抽屉宽 `280`。 | `lib/ui/desktop/sidebar.dart`；`lib/ui/desktop/workspace.dart` |
| 首页主体 | 在 `1280` 窗口宽度、`205` 侧栏下，工作区宽 `1075`。主体左右内边距分别为 `15 / 12`，可用宽约 `1048`；右栏宽 `282`、两栏间距 `14`，左主栏宽约 `752`。 | `lib/ui/v4/v4_workspace.dart:232–240`；`lib/ui/v4/v4_content_primitives.dart:95–107`；`lib/ui/v4/v4_home.dart:62` |
| 首页横幅 | 横幅位于左主栏，参考宽约 `752`。统一外框按第二张横幅素材比例 `2169:725`，高度约 `251`；圆角 `12`。第一张素材带内嵌侧边留白，使用 `1.04` 倍中心缩放裁齐。截图中的旧比例 `782:256`（约 `752 × 246`）已由统一第二张横幅外框的比例替代。 | `lib/ui/v4/v4_home.dart:171–173,214–230` |
| 首页游戏卡片 | 默认展示一行最多 `5` 张；参考卡片约 `140 × 229`，封面区域高 `116`，卡片水平/行间距 `13`。卡片宽度随主栏可用宽度计算。 | `lib/ui/v4/v4_home.dart:99–102,435–456` |
| 首页最近浏览 | 面板高 `171`，最多显示最近 `3` 条记录；条目使用固定三槽位布局，单条最大宽 `126`、间距 `8`，不足三条时不拉伸。缩略图比例为 `16:9`，优先显示横幅素材，并显示相对浏览时间。 | `lib/ui/desktop/home_pane.dart` |
| 收藏状态按钮 | 游戏库预览中的“喜欢/已喜欢”按钮固定为 `104 × 40`；详情页对应按钮固定宽 `108`、高 `48`。状态切换只替换内部图标、文案和配色，并使用淡入淡出过渡，不改变外框尺寸。 | `lib/ui/desktop/games_pane.dart`；`lib/ui/desktop/game_detail_pane.dart` |
| 右侧首页卡片 | 右栏宽 `282`；个人中心高 `255`、聚会面板高 `157`、快捷入口高 `169`、底部横幅高 `104`；区块之间垂直间距 `12`。 | `lib/ui/v4/v4_home.dart:62,637–652,699–703,786–790,825–829` |

## 响应式规则

| 工作区宽度 | 导航形态 | 说明 |
| --- | --- | --- |
| `≥1200` | `205` dp 完整侧栏 | 标准桌面导航。 |
| `760–1199` | `76` dp 图标栏 | 保留导航图标，收起文字。 |
| `<760` | 抽屉导航 | 侧栏从主布局中移除，通过导航按钮打开 `280` dp 抽屉。 |

主页左右栏在窄窗口下由 `V4ContentColumns` 自适应重排；表中的 `752 / 282` 等主体尺寸只作为标准参考窗口下的基准。
