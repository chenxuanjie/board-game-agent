# V4 Windows 桌面界面迁移说明

## 范围

- 当前分支：`codex/v4`。
- `tmp/board_game_assistant_v4` 仅作为只读视觉与交互参考，没有修改。
- Windows 原生端启用 V4 暖色界面；Web 和移动端继续使用原布局。
- V4 组件不依赖 Windows API，窗口拖动、缩放和窗口按钮由外层按平台启用，便于后续迁移 Web。

## 已接入的真实功能

| V4 入口 | 数据与操作 |
| --- | --- |
| 首页 | 真实游戏目录、推荐卡片、最近游戏/当前选择、进入详情、AI 助手、规则查询、活动通知 |
| 游戏库 | 真实游戏封面与元数据、分类、人数/难度筛选、目录/名称/评分排序、悬停动画、详情与规则入口 |
| AI 助手 | 复用现有会话、模型、流式回答、工具轨迹、引用、语音、取消与重试链路 |
| 规则查询 | 复用现有 WebDAV 规则资料刷新、筛选、下载、缓存、打开、删除和规则抽屉 |
| 设置 | 真实语言设置；“完整设置”保留 AI 服务、WebDAV、下载、语音、更新和原 Web/旧界面主题配置 |
| 搜索与通知 | 顶栏复用现有全局搜索和活动中心 |

排行榜、我的收藏、社区和个人中心保留参考工程入口并统一显示“未开放”。

## 真实数据与缺失字段

游戏名称、封面、数量、评分、评分人数、人数、时长、难度、分类和说明都来自主项目 `GameInfo` 与实际目录；字段缺失时显示 `—` 或 `-`。界面不使用参考工程的游戏示例数据。

当前主项目没有以下可靠数据或持久化接口，因此没有伪造展示：

- 用户账号、头像、昵称、等级和会员信息；
- 排行榜服务与全站排名；
- 收藏/心愿单持久化；
- 社区帖子、回复和互动；
- 聚会/活动创建与报名；
- 个人游玩次数、最近对局时长和累计时长；
- 缓存总字节数、统一清理接口和 UI 缩放设置。

设置页中对应的原型项目显示 `- · 未开放`。当前暖白、橙色与木色方案已注册为可持久化主题“暖木书房”（`warmwood_study`）；Windows V4 使用该主题呈现，完整设置可管理主题偏好。

## 入口调整

- 为保持参考工程侧栏布局，规则资料库没有额外占用侧栏项，可从首页“规则查询”或游戏详情进入。
- 旧侧栏的人数与难度分类移入游戏库筛选弹窗；规则资料类型筛选保留在规则资料页。
- 完整模型、WebDAV、资源下载、语音、更新和关于设置集中在 V4 设置页的“完整设置”。
- 原活动中心移至顶栏通知按钮；原全局搜索移至 V4 顶栏搜索框。
- 旧桌面壳的“新建”按钮没有独立业务能力，因此 V4 不展示该按钮。

## 验收与回滚

V4 widget 测试覆盖 1100×700、1280×800 和 1920×1080，验证首页、游戏库、设置、规则资料、未开放入口以及真实控制器接线，并检查布局溢出。发布构建通过后，Windows 可执行文件位于 `build/windows/x64/runner/Release/board_game_agent.exe`。

回滚只需切回原分支；本次没有修改数据格式、偏好键或参考工程。
