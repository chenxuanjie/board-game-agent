# 账号与资源连接

Android、Windows、Web 将知识库状态、检测、公共地址、配置导入导出和凭据管理集中到“账户 → 知识库连接”。设置页只保留账户入口；没有注入账户服务的旧宿主仍保留资料状态入口。两组地址是同一台 NAS 的内外网入口，可直接拖动排序，账户页还提供键盘可用的上移/下移菜单。

地址只填写 HTTPS 主机（不含端口或 friend）；每组地址分别设置登录端口（默认 5001）和 WebDAV 端口（默认 5006）。知识库存储目录默认 friend，允许 friend/rules 等子目录。目录与主机、端口分开保存，后续增加其他用途目录时无需拆解 URL。资源仍使用目录下的 apps/board_game_agent/board-game-lib，更新仍使用 apps/board_game_agent/updates/manifest.json。

首次升级从旧来源 URL 和 v3 登录配置迁移为 v4，保留地址、顺序、自定义 WebDAV 端口与目录。旧登录地址作为稳定账号环境；改顺序或切换已配置别名不会拆分本地账号或云同步。地址属于同一 NAS 的显式受信任别名；修改地址或登录端口需要先退出账号，以免混用不同 NAS 的相同 UID。

登录页显示配置好的完整 DSM 登录网址，默认选中上次使用的入口；可以选择另一个入口或填写自定义 HTTPS 登录地址（不含 friend 目录）。明确选择后只验证该入口，不暗中改用其他地址。未指定入口的内部调用仍按原优先级回退；只有网络、超时、服务不可用才回退，密码错误、账号限制、限流和验证码挑战停止回退。验证码继续在原地址验证，可取消后重新选择地址。

账号提交与独立会话确认共用 3 秒认证期限，恢复会话的网络确认也最多等 3 秒。超时取消网络请求、拒绝晚到结果并提供重试；异常候选会话另外进行短时撤销及本地清理，不能把未验证账号当成登录成功。已缓存的账户在校验超时时保留离线状态。账号数据本地隔离仍必须完成，云同步网络请求在后台运行，资料凭据/缓存保存失败不会撤销已经验证的账号登录。

群晖适配器在登录方法内部已经用 SID 查询并确认真实 UID，通过公共包的显式“登录结果已验证”能力复用这一结果，不再马上发起相同 UID 请求。其他适配器继续独立验证；每次恢复旧会话也继续向服务端验证。云同步初始化及昵称读取在账号本地隔离完成后后台运行，失败不会触发全局账号数据切换错误页。

自定义地址若匹配现有入口，沿用原账号环境；未知地址按新 NAS 隔离，成功后保存为新的单入口连接并沿用知识库目录/WebDAV 端口，不向旧入口转发新地址的凭据。自定义登录失败或取消验证码后恢复原连接，密码与验证码不写入公共配置。恢复已保存会话仍验证实际签发会话的地址，不将 SID 转发给另一个地址。

资源访问将这些地址视为同一台 NAS 的入口，而非不同资料源。检测并发读取每个入口的真实知识库 catalog.json，不下载海报、不用本地缓存冒充连接成功。任一入口返回有效知识库目录后，整体立即显示“资源可用”；其余入口继续完成各自结果，不再因为一个入口失败将设备降级为“部分可用”。全部失败才显示“资源暂不可用”。

移动、桌面账户页共用整体状态卡，点击信息入口再查看各地址的可用性、权限/登录/目录/超时原因；详情中保留拖动排序和连接编辑。资源 GET、HEAD、PROPFIND 也并发尝试入口，先成功的结果胜出并取消其余请求，缓存只由胜出的响应写入。HTTP 请求上限 8 秒，单入口递归目录扫描总上限 1 分钟。网络变化后曾失败的入口仍可参与下一次读取，不因旧状态被永久排除。

重复检测合并为同一轮。地址变更、切换账号和控制器退出会取消旧检测并使其结果失效；保存排序不会将另一个入口的状态混用。实际文件下载可沿用已有离线缓存，但连接检测始终以真实网络读取为准。此行为不改变登录顺序、凭据归属或账号云同步。

登录独立验证成功后，将用于 WebDAV 的同一份账号凭据保存到按环境与已验证用户隔离的原生安全存储。WebDAV 配置是派生缓存，不是另一个账号来源；资料请求仅向已配置的 HTTPS 来源和目录根发送 Basic 凭据，GET/HEAD 不跟随重定向。退出登录清理当前账号的凭据，并恢复该 NAS 已保存的独立 WebDAV 连接；未配置独立凭据时清空派生凭据。取消或晚到的登录不会为其他账号配置资料。OTP 不保存。配置、导入导出、云同步和发布记录不含登录密码。

旧会话在用户名与旧 WebDAV 根目录匹配时安全迁移已有凭据；不匹配或旧版从未保存资源密码时需重新登录一次。新版安装包不再内置共享 WebDAV 账号密码，离线缓存仍可使用。发布工具自身的上传凭据留在仓库外 profile，不属于客户端登录配置。

公共连接配置是权威数据，来源列表及 WebDAV 地址由它投影生成。派生存储失败不会声称连接成功，保留重试入口，启动时重新生成。导入多项设置仍复用安全恢复日志：失败或中断恢复账号公共配置、WebDAV 派生缓存、来源与 AI 配置。导入不替换已登录凭据，也不会自动登录。

免登录时可展开“仅使用 WebDAV”，保存或清除独立资料账号与密码，不创建群晖身份、不切换个人数据、不开启账号云同步。凭据沿用安全存储，以 guest + NAS 环境隔离；重启恢复，登录时暂用已验证用户凭据，退出后恢复独立凭据。地址或账号切换期间暂停旧凭据投影，资源请求只向当前配置的 HTTPS 主机与目录根发送凭据；新 NAS 不继承原环境凭据。密码不回填表单，保存成功后清空输入。公共配置及导出不包含独立凭据。

Web 保留访客模式，可以保存独立 WebDAV 资料凭据，不尝试 DSM 登录。浏览器安全存储依赖安全来源（HTTPS 或 localhost），跨域读取仍需服务端 CORS；本次没有新增代理或改变传输策略。

账户页可用宽度达到 1000 dp 且文字缩放小于 150% 时采用账户/知识库 4:6 双栏，最大宽度 1180 dp；窄屏和大字体采用最大宽度 600 dp 的纵向分区。两种布局复用账户服务与操作，窗口跨断点时保留输入草稿和展开状态。地址与独立凭据按需展开，避免抢占登录主操作。

验收覆盖 320/390/1280 dp 的凭据保存、密码清空、重启、登录/退出隔离、未知来源拒绝、存储失败重试与 Web 访客恢复。真实 NAS 凭据与原生系统安全存储的端到端验证需私有测试环境，不能由内存夹具证明。回滚代码使用 b938999；回滚前可在账户页清除独立凭据，旧版忽略新增 guest 安全存储键。

协议依据：[群晖 DSM 登录官方指南](https://kb.synology.com/en-us/DG/DSM_Login_Web_API_Guide/2)。继续复用 app_identity、flutter_secure_storage、webdav_settings 和 app_ai_client 现有网络工厂，没有新依赖。v4 公共配置键与旧 v3 键相同；历史版本迁移需保留 v4 配置或恢复旧版备份，个人数据和云同步日志不改格式。
