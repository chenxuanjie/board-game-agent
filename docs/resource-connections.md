# 账号与资源连接

Android、Windows 共用“账户 → 服务器与资料”。设置页的来源编辑也进入此页面；没有独立 WebDAV 账号密码表单。两组地址是同一台 NAS 的内外网入口，可直接拖动排序，账户页还提供键盘可用的上移/下移菜单。

地址只填写 HTTPS 主机（不含端口或 friend）；每组地址分别设置登录端口（默认 5001）和 WebDAV 端口（默认 5006）。知识库存储目录默认 friend，允许 friend/rules 等子目录。目录与主机、端口分开保存，后续增加其他用途目录时无需拆解 URL。资源仍使用目录下的 apps/board_game_agent/board-game-lib，更新仍使用 apps/board_game_agent/updates/manifest.json。

首次升级从旧来源 URL 和 v3 登录配置迁移为 v4，保留地址、顺序、自定义 WebDAV 端口与目录。旧登录地址作为稳定账号环境；改顺序或切换已配置别名不会拆分本地账号或云同步。地址属于同一 NAS 的显式受信任别名；修改地址或登录端口需要先退出账号，以免混用不同 NAS 的相同 UID。

每次登录从优先级首位开始。网络、超时、服务不可用才回退下一组；密码错误、账号限制、限流和验证码挑战停止回退，验证码继续在发起挑战的地址验证。恢复已保存会话仍验证实际签发会话的地址，不将 SID 转发给另一个地址；切换网络后需要重新登录时会重新按顺序尝试。

登录独立验证成功后，将用于 WebDAV 的同一份账号凭据保存到按环境与已验证用户隔离的原生安全存储。WebDAV 配置是派生缓存，不是另一个账号来源；资料请求仅向已配置的 HTTPS 来源和目录根发送 Basic 凭据，GET/HEAD 不跟随重定向。退出登录清理当前账号的凭据和派生缓存，取消或晚到的登录不会为其他账号配置资料。OTP 不保存。配置、导入导出、云同步和发布记录不含登录密码。

旧会话在用户名与旧 WebDAV 根目录匹配时安全迁移已有凭据；不匹配或旧版从未保存资源密码时需重新登录一次。新版安装包不再内置共享 WebDAV 账号密码，离线缓存仍可使用。发布工具自身的上传凭据留在仓库外 profile，不属于客户端登录配置。

公共连接配置是权威数据，来源列表及 WebDAV 地址由它投影生成。派生存储失败不会声称连接成功，保留重试入口，启动时重新生成。导入多项设置仍复用安全恢复日志：失败或中断恢复账号公共配置、WebDAV 派生缓存、来源与 AI 配置。导入不替换已登录凭据，也不会自动登录。

Web 保留访客模式，可以配置公共连接信息，但不尝试原生登录或保存群晖密码。本次请求只构建发布 Android，不将旧 Windows/Web 产物标记为当前版。

协议依据：[群晖 DSM 登录官方指南](https://kb.synology.com/en-us/DG/DSM_Login_Web_API_Guide/2)。继续复用 app_identity、flutter_secure_storage、webdav_settings 和 app_ai_client 现有网络工厂，没有新依赖。改动回滚到 85bfe64；v4 公共配置键与旧 v3 键相同，回滚前需保留 v4 配置或恢复旧版备份，个人数据和云同步日志不改格式。
