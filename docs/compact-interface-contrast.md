# 紧凑界面对比度

- “我的”两个快捷入口分别使用主题 primaryContainer / secondaryContainer，与页面背景分离；图标和标题使用对应前景色，卡片保留完整主题描边。“最近浏览”空状态增加同样的边界。
- 首页快捷图块与桌游库卡片补齐描边；共享 ContentCardSurface 不再把描边淡化为 65%，覆盖推荐桌游、最近 AI 对话和相关游戏。
- 暖木书房与晚霞海岸的次级容器颜色加深，帮助首页活动卡、详情统计和设置内部资料源列表分组。夜幕棋局也增强描边亮度。共享主题令牌同步影响宽屏，不保存页面专属颜色或改变用户主题选择。
- 浅色主题辅助文字加深；详情简介增加描边，详情属性标签改为可读的主题正文色。桌游库原有彩色属性标签保持原样。

数值回归覆盖三种主题：次级容器与页面背景对比至少 1.12:1，描边与普通卡片至少 1.5:1，辅助文字与普通/次级/变体容器至少 4.5:1。前两项为项目内视觉分层基线，不表示所有 UI 已达到无障碍认证。普通页面边界依靠描边与底色共同表达。

移动内容布局回归保留窄宽尺寸与放大文字检查，并验证快捷入口、推荐卡片和桌游库使用正确的主题边界。按用户要求不生成测试渲染图；真实 Android、Windows 原生运行与真实语音权限尚未实测，不重建或发布安装包。改动不涉及配置、会话或用户数据迁移，可通过审阅并回退上述 UI/主题差异恢复。
