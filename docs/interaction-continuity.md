# 浏览位置与交互反馈

本轮约定于 2026-10-12，适用于 Windows、Android 和 Web 的宽窄布局。

## 浏览位置

桌游库的搜索、分类、排序、人数/时长/类型/难度/评分筛选、滚动位置以及当前工作区保留在本次运行的账号状态中。退出程序不保存到磁盘，不进入私人或公共云同步；切换账号时替换状态对象，旧页面的迟到回调不能写入新账号的浏览状态。

桌面按页面分别使用滚动控制器，进入详情不覆盖桌游库的位置。紧凑端切换底部标签后恢复库状态，Web 更换宽窄外壳时复用同一份库状态。原有手机控件不增加完整桌面筛选面板，但保留宽屏选过的条件，并提供清除筛选与排序入口。

位置记录稳定游戏 ID、原列表下标、卡片相对视口的偏移及像素位置。列数变化后先定位该游戏所在行，再用真实布局修正；游戏移除时回到原下标附近。处于顶部时保持顶部，主动改变搜索或筛选时回到结果顶部。所选游戏沿用 AppController；滚动恢复不调用会同时切换 AI 会话的 selectGame。

## 图片与列表

图片容器沿用既有宽高和封面比例。加载中的空白使用同尺寸主题底色，失败再显示缺图图标。首次真实解码完成后渐入；缓存帧直接展示。已有图片刷新时保留上一帧，避免中途退回缺图占位。

桌游库已出现过的游戏返回时不重播首屏入场。新增条目与排序位置、名称、评分、封面路径变化的条目使用局部 200 ms 淡入和最多 4 dp 位移；稳定条目及其输入、图片状态保持挂载，不因控制器通知重播。

## 局部操作

- 评论发布保留原有持久化队列、稳定操作 ID 和按钮内转圈，确认发送后清理草稿。
- 点赞按评论 ID 防重复点击，只锁定该点赞按钮，保留本机选择。同步失败显示局部重试，重试同步不会再次翻转选择。
- 收藏保留本机写入中的按钮反馈与已保存后的爱心反馈；添加成功不额外弹全局提示，取消收藏仍保留撤销入口，保存失败仍显示必要说明。
- 资料下载选择目录时不展示伪下载进度，真正下载和落地时在该资料行转圈；落地后显示“已下载”，完整路径放在 Tooltip。失败在对应行提示，并可通过下载操作重试。当前顺序处理资料操作，其他入口明确禁用并说明正在处理，不静默忽略点击。

当前下载接口没有字节进度回调，使用不定进度，不伪造百分比。资料批量更新的平滑进度只插值实际已完成项数，不提前达到目标，不延迟业务结果来播放动画；完成状态保留真实结果。

## 菜单与面板

复用 AppMotion：菜单/确认弹窗进入 180 ms、退出 140 ms；底部面板进入 240 ms、退出 180 ms；会话抽屉进入 240 ms、退出 180 ms，并分别使用进入/退出曲线。搜索排序、筛选入口防重入；共用弹窗、底部面板和会话抽屉的入口保护持续至退出动画完成，连续点击不会叠加相同类型的浮层。

系统减少动画开启时，图片、条目和进度立即收敛到真实状态，菜单和面板过渡时间归零。动效只呈现状态，不使用定时器假造完成或等待。

## 验证

回归入口：interaction_continuity_test.dart、game_comments_test.dart、desktop_workspace_test.dart、mobile_home_test.dart、app_motion_test.dart、conversation_drawer_test.dart。

覆盖网格列数改变和卸载后的游戏锚点恢复、搜索/排序保留、账号状态替换、快速重复点赞、面板退出中重开保护、图片尺寸稳定、进度不超前，以及运行中开启减少动画。Widget 回归不代表实际 Windows GPU 帧耗时或 Android 真机体验已测量；本轮不构建或发布产物。

2026-10-12 验证：全量 600 项测试通过；进度重启与资料更新的补充回归 35 项通过，最终静态分析无问题。格式与 Git 差异检查通过，Android 测试过程产生的临时插件注册变更已恢复。本轮未构建或发布。
