# 影院主题 v1

版本：1.0。确认日期：2026-10-13。

状态：在 `codex/v5` 分支实现首版影院主题。影院以独立编码替换晚霞海岸，接入语义配色、共享首页构图、桌面库海报、局部玻璃及设置开关，复用原业务。数值是本项目基线，不是 Netflix 或 Apple 公布的参数。本轮按用户要求构建本地 Windows EXE 和 Web，不上传。设备性能和真实账号网络交互不以布局测试替代验收。

## 1. 已确认的范围

- 新增可切换的完整视觉主题，中文名“影院”、英文名“Cinema”，存储代码 `cinema`；替换晚霞海岸原有选项位置，保留暖木书房默认值和夜幕棋局。不提供晚霞海岸配置兼容或迁移；影院独立使用 `cinema`。
- 深炭灰、暖白和少量珊瑚红强调，配合适度玻璃层次；应用名称、图标及真实桌游资料保留。
- 背景采用桌游图片关联的低亮度氛围，内容区随可用工作区自适应。原型的拟真房间、固定悬浮窗口、电量胶囊和播放器不进入桌游产品界面。
- 首页采用大横幅与推荐内容行；桌游库提供完整网格、搜索、筛选和排序；详情顺序为介绍/规则 → 相关游戏 → 独立评论区。
- AI、账户、设置保留功能分组，使用同一套材质与控件。Windows、Web、Android 共用视觉角色，分别适配宽屏和触控。
- 账号、收藏、排行、评论、资料下载、AI 会话和同步继续使用现有模型与服务；主题不创建另一套业务状态。

## 3. 颜色角色

“角色”指界面用途：页面背景用作最底层，内容面板承载正文，浮层承载菜单/弹窗，控件承载操作。它不指人物或虚拟角色，也不要求桌游图片出现人物；盒面、地图、配件或其他真实桌游图片均可作为视觉素材。

以下为不透明 sRGB 基线，颜色统一在主题中定义；页面按角色取值，不再直接写“某页专用黑色/红色”。

| 角色 | 基线 | 用途 |
| --- | --- | --- |
| `pageBackground` | `#0E1015` | 页面底色、图片不可用时的氛围回退 |
| `surface` | `#171A21` | 正文、评论、阅读与表单背景 |
| `surfaceContainer` | `#20242D` | 浮层的实体回退、选项分组 |
| `surfaceVariant` | `#262B35` | 次级内容、加载占位 |
| `inputSurface` | `#1B2029` | 输入框 |
| `textPrimary` | `#F6F2EC` | 标题、正文 |
| `textSecondary` | `#B7B8C2` | 属性、帮助和次级说明 |
| `textMuted` | `#898E9B` | 时间、数量等辅助信息；不是禁用色 |
| `divider` | `#353B47` | 装饰性分隔，不单独承担控件识别 |
| `controlOutline` | `#737B8A` | 需要描边识别的输入框、边框按钮 |
| `primary` | `#FF6B5D` | 珊瑚红主操作、选中与重点强调 |

| `primaryContainer` / `onPrimaryContainer` | `#422725` / `#FFE4DF` | 较弱的选中底板及对应内容 |
| `focusRing` | `#FFF1CA` | 键盘焦点，区别于选中底板 |

| `disabledForeground` / `disabledBackground` | `#717786` / `#252932` | 真正不可操作的控件；必要说明仍用正常副文案 |

珊瑚红只标记重要操作或选择，不填满每张卡片。失败同时显示错误图标、文案或重试，不能只用与强调色接近的红色区别状态。

对比度按 [WCAG 2.2 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)验收：普通文字至少 4.5:1；必要的控件识别与状态图形至少 3:1。正文统一按 4.5:1 检查，不借大字例外压低门槛。

2026-10-13 对不透明基线计算：正文/内容底约 15.61:1，副文案/浮层约 7.88:1，辅助文案/浮层约 4.74:1，深色字/珊瑚红约 6.65:1，控件边框/输入底约 3.84:1。暖白字/珊瑚红仅约 2.51:1，不用于普通按钮文字。这些计算不代表图片或玻璃合成后的可读性已通过验收。

## 4. 氛围与材质

### 背景

- 首页横幅使用当前推荐桌游图片，详情使用当前所选图库图片。桌面外壳以所选桌游图片提供淡化氛围，正文与表单保持实体底；不随鼠标移动换图。紧凑端采用轻量深色底和主视觉图片，避免全窗模糊。
- 图片氛围是装饰层，与内容图片尺寸独立，不承担文字或点击。图片淡化并叠加页面暗底；不能让图片亮度直接改变表单可读性。
- 背景颜色只影响装饰层，不改变主操作、成功、错误等语义色。色彩过渡在图片已就绪后发生，不阻塞浏览和下载。
- 缺图、离线或解码失败时直接回退页面底色，不为背景装饰另发资料请求；手机背景优先使用已解码的小图或轻渐变。

### 表面分工

| 材质 | 使用位置 | 不透明度与模糊基线 |
| --- | --- | --- |
| 实体内容底 | 正文、评论、AI 消息、设置表单、游戏网格卡片 | 使用 `surface`；不叠加 BackdropFilter |
| 导航玻璃 | 宽屏侧栏/工具区、紧凑导航 | 炭灰底 alpha 0.90；宽屏 sigma 12，紧凑端默认 0 |
| 浮层玻璃 | 菜单、抽屉、底部面板 | 炭灰底 alpha 0.94；宽屏 sigma 16，紧凑端默认 0 |
| 主视觉蒙层 | 横幅、详情大图上的信息 | 靠文字一侧暗、靠图片一侧轻；按实际图片校验对比，不使用一个透明度覆盖所有图片 |

模糊值是本项目起始基线和上限约束，不是质量保证。玻璃只在有背景层次可感知的局部区域使用，必须按控件边界裁切，不嵌套多层模糊。悬浮状态通过底色、细边界和有限阴影表达，不用持续发光或改变布局大小。

影院设置已提供共用的关闭玻璃能力；关闭后切换到不透明底色，文字、焦点和布局保持不变。高对比度模式下共用玻璃组件也使用实体底；系统专用减少透明度 API 尚未接入。该选项属于展示偏好，不加入 NAS 同步协议。性能不达标的目标设备使用实体回退，不宣称任意设备都能高帧率运行。

## 5. 字体、间距与形状

继续使用已打包的 Noto Sans SC 字族及现有 Emoji 回退，不引入未声明的 Inter 或模仿 Netflix 标志字体。单位是 Flutter 逻辑像素；文字遵循系统 TextScaler，不整体 Transform 缩放。

| 文字角色 | 宽屏 | 紧凑端 | 字重 / 行高 |
| --- | --- | --- | --- |
| 主视觉标题 | 40 | 30 | 700 / 1.18 |
| 页面标题 | 28 | 24 | 700 / 1.25 |
| 分区标题 | 20 | 18 | 600 / 1.30 |
| 卡片标题 | 16 | 15 | 600 / 1.30，最多两行 |
| 正文 | 16 | 16 | 400 / 1.55 |
| 次级正文 | 14 | 14 | 400 / 1.45 |
| 数量、时间、帮助 | 12 | 12 | 400 / 1.40 |
| 按钮与导航 | 14 | 14 | 600 / 1.25 |

有正文的卡片自然增高；只有封面/主视觉使用固定图片比例。标题和操作不得靠 6～10 dp 小字或横向压缩来挤入面板。200% 字号时重排指标和按钮，内容能滚动，菜单和输入操作仍可访问。

复用 UiTokens：普通卡片圆角 16、分组 20、控件 12；胶囊仅用于适合该形状的短标签和切换控件。间距基线为 4/8/12/16/24/32/48，页边距紧凑端 16、宽屏 24～32；文字密集区域保持 12～16 的段间距，不在每页再定义一套比例。

主/次按钮可视高度宽屏 40、紧凑端 48；图标按钮点击区域宽屏至少 40×40、触控至少 48×48，图标 20～24。触控基线是本项目选择，不能把 [WCAG 2.5.8 的 24 CSS px 门槛及其例外](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)解释成所有按钮都可以缩到 24。

## 6. 三端构图与页面规则

### 外壳

- 宽屏采用侧栏与自适应内容区；复用现有 205 dp 完整侧栏和 76 dp 图标栏的角色，不移植固定大小的居中视窗。
- 影院 Web 以宽度选择外壳：1100 dp 起使用桌面构图，1200 dp 起显示完整侧栏；不足 1100 dp 使用紧凑构图。窗口高度只影响滚动与面板最大高度，不应让宽电脑窗口因高度小于 800 自动变成手机。
- 该宽度判断仅应用于影院，其他主题保留既有高度/宽高比判断。Windows 既有窗口默认/最小尺寸和中央窗口框架保留。
- 手机和窄屏 Web 保留底部主导航。搜索仍按既有页面范围展示，不增加在所有页面重复出现的搜索栏。
- 首页与库内容最大宽度沿用现有 1480/1500 dp 的角色；表单、账户与阅读区域使用各自更窄的限制。超宽空间增加列数或留白，不按屏幕比例无限放大字号。
- 更换主题、宽窄布局或返回详情保持当前账号的浏览位置、搜索、筛选、所选游戏与草稿。遵循 [浏览位置与交互反馈](interaction-continuity.md)，账号切换清空本次浏览状态。

### 页面

| 页面 | 构图与主任务 |
| --- | --- |
| 首页 | 大横幅展示真实推荐/专题，下面依次提供今日推荐、最近浏览等真实内容行。宽屏横幅采用约 2.4:1 框架、自然高度下限 320；紧凑端图片约 16:9，文字可置于图下独立信息区。字体放大或文字较长时自然增高，不把操作压进固定高度。 |
| 桌游库 | 分类/搜索与筛选工具区 → 检查细条 → 完整网格。宽屏最小卡宽 192、横/纵间距 16/24、最多 6 列；紧凑端最小卡宽 136、间距 12、最多 4 列。列数为 `floor((内容宽 + 间距) / (最小卡宽 + 间距))`，限制在 1 与平台上限之间，再等分实际宽度；320 dp 下两列。首页内容行不替代全量游戏目录。 |
| 游戏卡片 | 库封面框 3:4，完整呈现盒面；真实横幅素材可用于首页横向卡片。封面不可用于拉伸补满错误比例。卡片提供标题、资料评分及必要属性；选中与聚焦分开表示。 |
| 游戏详情 | 主视觉目标 16:9，长文在实体内容区；主操作使用现有喜欢、规则与询问 AI。介绍/规则 → 相关游戏 → 独立评论，评论不恢复成第三个介绍标签。图库选择仍按现有账号浏览偏好恢复。 |
| 排行榜 | 保留真实收藏人数、名次与比例条，仅统一表面、字重与操作反馈；不制造影视“热度”或虚构评分。 |
| AI | 保留会话、真实阶段、工具轨迹、引用、输入、失败和重试。正文使用实体底，玻璃限于工具区、菜单及历史抽屉。流式更新不重播整页动画。 |
| 账户 / 我的 | 保留现有账户入口、真实统计、连接与同步状态；头像信息可以有层次，表单和数据必须清楚。登录能力不因换主题改变，Web 仍为当前访客模式。 |
| 设置 | 继续使用通用、账户、AI、主题、桌游检查、关于等功能分组。以清晰标签和一致控件表达，不将配置伪装成电影海报。 |

内容行通过真实卡片数量确定滚动范围：鼠标有悬停/聚焦入口及滚动条，键盘可进入每个操作，触控可滑动；不使用 `.take(2/4/6)` 造成超出屏幕的游戏不可访问。任何箭头不能只是装饰。

## 7. 状态与动效

统一控件状态为：空闲、悬停、聚焦、选中、禁用、执行中、成功、空结果、失败。加载不清空已有内容；可恢复的失败有原因和局部重试；禁用时明确原因。不能依赖鼠标悬停才能执行触控主要操作。

| 行为 | 进入 / 退出基线 | 限制 |
| --- | --- | --- |
| 悬停、聚焦、颜色、首帧图片反馈 | 160 ms | 卡片最多上移 2 dp；缓存图片立即显示 |
| 页面与局部条目变化、真实进度 | 200 ms | 变化条目最多位移 4 dp；稳定条目不重播，不重建草稿 |
| 菜单、确认弹窗 | 180 / 140 ms | 退出结束前防重入，但选择立即交给业务 |
| 抽屉与底部面板 | 240 / 180 ms | 快速关闭、重开、改变尺寸都要自然收敛 |
| 封面衔接、手动滚动 | 280 ms | 使用真实起点和目标；过期导航或尺寸变化取消 |

进入采用现有 easeOutCubic，退出采用 easeInCubic，复用 AppMotion。背景更新只在目标图片准备好后短暂过渡，不增加常驻粒子、循环扫光、3D 倾斜或自动播放音视频。

评论发送、点赞、收藏与下载继续沿用真实本机/远端完成边界及局部反馈。未知字节数的下载使用不定进度；确定项数的更新仅插值实际值，重新开始立即回到新任务值。动画不提前宣布成功，也不延迟业务完成来展示效果。

系统减少动画时立即呈现最终状态并暂停装饰性自动运动；关闭玻璃时使用实体底。两种偏好分别控制动效与材质，不能把关闭动画当成已经关闭模糊。

## 8. 实现映射

本文规则需要落实到令牌、组件样例和验收，不能只保留效果图。

| 层次 | 现有入口与计划 |
| --- | --- |
| 选择与持久化 | 已在 ColorSchemeOption/PaletteRegistry 用 `cinema` 替换晚霞海岸；沿用现有保存与导入导出，仅接受影院自身编码，当前默认主题不变 |
| 语义颜色 | AppPalette 统一两端语义角色；如需 textMuted、装饰线与控件边框区分，由共享主题扩展一次，不在页面造独立颜色表 |
| 形状与动效 | 复用 UiTokens、AppMotion、AppModals、图片反馈、SmoothProgress 和浏览位置组件 |
| 材质与布局 | `ui/shared/cinema/` 提供 CinemaHomeContent、CinemaPoster、CinemaAmbient、CinemaSurface；玻璃仅用于导航和浮层 |
| 桌面接线 | buildDesktopTheme 接入影院主题；desktopColors/desktopTone 按语义映射旧桌面组件，其他主题保持既有外观 |
| 功能分组 | 修改展示组件，复用 AppController、AccountService 与各领域服务；不新增评论或同步协议 |

先建立按钮、输入框、导航、菜单、游戏卡片、主视觉、评论和进度的组件样例，再接首页/库/详情，最后覆盖 AI/账户/设置/资料页。所有旧主题共用的行为回归必须保持通过，避免出现新主题和旧主题各有一套不同数据流程。
