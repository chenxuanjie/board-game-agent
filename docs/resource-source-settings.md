# 资料源与连接界面

资料区使用共享 `ResourceSourceList` 逐项显示来源名称、访问地址与连接状态，替代“2 个资料源 / 已连接 1/2”的汇总。地址展示移除 URI 中的用户信息、查询和片段，不将网络错误原文或密码直接显示在状态旁。

桌面保留“资料与同步”分组；资料源检测是独立操作，WebDAV 地址、账号、密码和保存检测按钮在“WebDAV 连接设置”内按需展开。紧凑端默认展示相同来源列表，把现有拖动排序与检测入口放在“调整优先级”中，保持排序和保存行为。

连接状态分别覆盖已连接、未连接、检测中、未检测和需检查，使用主题语义颜色和图标。共享控件不发起网络请求，不改变资料源的存储格式、优先级或 WebDAV 同步协议。WebDAV 保存后的资料源替换行为沿用原实现。

验证使用模拟的本地/远程资料源状态与模拟 WebDAV 检测器，覆盖来源名称与状态关联、展开后的原有字段保存、以及紧凑页面导航。没有访问真实 WebDAV，也没有上传数据。

回滚可以审阅基线 `4db0307` 后对应 UI、控制器及测试的差异；没有用户数据迁移。
