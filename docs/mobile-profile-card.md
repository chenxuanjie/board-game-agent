# 手机资料卡片

“我的”页由 `MobileMineContent` 显示当前账号资料，`AccountService` 继续负责登录、昵称和账号数据隔离。头像、名称、状态及右侧箭头是一块完整点击区域，统一进入现有 `AccountScreen`；移除独立账户按钮、重复登录按钮和无对应会员机制的皇冠标签。资料卡采用主题表面和圆角，去除曲面缺口与固定右侧占位，长名称允许两行，大字体时高度自然增加。

已登录显示当前账号昵称及“已登录”，未登录显示保存的访客昵称或“未登录”，入口提示“点击登录”。账号昵称仍在账户详情修改，返回后通过 AccountScope 更新；访客昵称保持原存储键，不混入账号数据。没有 AccountScope 的旧界面保留本机昵称编辑，仅将入口合并到资料行。连续点击只打开一个资料路由。

收藏统计点击进入现有“我的喜欢”；AI 对话统计打开现有 ConversationHistoryPanel，选择已有会话或成功创建新会话后进入聊天页面。单纯打开历史不创建会话。历史弹层新增可选打开回调，原桌面/聊天入口保持默认行为，不复制会话持久化或删除逻辑。

交互参考 Flutter 官方 [ListTile](https://api.flutter.dev/flutter/material/ListTile-class.html) 的整行点击与触控范围，以及 [InkWell](https://api.flutter.dev/flutter/material/InkWell-class.html) 的 Material 点击、聚焦和悬停反馈。使用项目当前 Flutter SDK 的组件，按自定义资料行布局组合 Row/Column，而不增加第三方依赖。

回归覆盖头像与名称点击、重复点击、修改昵称返回、退出后恢复访客资料、收藏/会话统计独立点击、历史选择往返、320/390/720 dp 与 200% 字号。APK 仍通过同一发布流程签名、排除桌游正文资料并推送 WebDAV；无连接的 Android 设备时，界面渲染与组件测试不代替实机安装验收。
