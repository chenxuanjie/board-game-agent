# 国庆专题页

首页国庆横幅进入独立路由，铺满窗口，不显示侧栏和搜索栏。返回首页恢复原首页位置；点击游戏封面进入现有详情页。

## 视觉与资源

- 按用户提供的 `1448 × 1086` 参考构图，背景铺满窗口，标题和托盘按统一比例居中适配。
- 设计坐标：标题区域 `(420, 92, 610, 342)`，清单托盘 `(234, 474, 996, 410)`。默认三款游戏及一张添加卡，卡宽 `226`、间距 `20`，更多游戏横向滚动。
- 背景 `assets/desktop/national_day/background.png` 为用户提供的无字原图；标题、光晕、装饰、虚线和卡片由 Flutter 绘制。
- 标题字体来自 [Google Fonts Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，原字体版本 `2.003-H1`、SIL OFL 1.1。只保留固定专题文案的字形，打包为约 18 KB 的 `NationalDayDisplay.ttf`；许可保留在 `assets/fonts/OFL-NotoSerifSC.txt`。正文及交互控件仍使用应用的 Noto Sans SC。
- 字形子集覆盖固定的“国庆专题、国庆聚会、国庆想玩、桌游清单、本次想玩、dde，敢来吗？”；修改标题文案时需同步重新生成子集。不得用于动态游戏名称或用户资料。
- Android 和窄屏 Web 使用独立的手机布局。竖版背景 `assets/mobile/national_day/background.png` 是用户提供的无字原图，铺满视口；不绘制假的时间、电量或手机外框。标题区高为内容宽度的 47%，云形面板左右留 16 dp，最大内容宽度 560 dp；首款游戏为横向大卡片，其余与添加按钮三列换行。小屏、大字体、横屏和更多游戏可纵向滚动。大卡使用对应横幅，小卡使用竖版封面，加载失败复用本地优先的游戏封面组件。

## 数据与交互

- 默认使用已收录的卡卡颂、璀璨宝石、自然和弦；游戏信息不足三款时从现有目录补齐，不虚构卡坦岛或只言片语的数据。
- 添加弹层支持搜索及排除已加入游戏；手机使用底部选择面板并为键盘留位，桌面使用对话框。移除和新增通过 AppController 中的同一个 NationalDayListController、PreferencesService 保存，键为 `national_day_game_slugs_v1`。两种布局共用清单状态与分享文本，不各自维护数据。空清单也会保存，再次进入不会自动恢复默认清单。
- 保存时禁用重复修改；读取失败提供重试，保存失败保留当前清单并提示重试。
- 右上角仅提供分享，点击复制清单文本，包含真实游戏名称、人数和时长。没有在线多人清单或云分享链接。
- 卡片底部使用点赞图标与“想玩 / 已投 + 票数”，表示想玩投票，完全独立于收藏。每个安装实例对每款游戏一票，可给多款游戏投票，再次点击取消；不虚构票数。删除清单卡片只改变个人清单，不撤销已有投票。
- 投票先保存到 `national_day_votes_v1` 本地缓存，写入失败保留原状态并提示重试。稳定随机安装 ID、自己的投票以及其他设备的票数缓存一并保存；重启后继续保留，离线取消也会立即正确扣除自己的票。
- 使用设置页已有的 WebDAV 地址与凭据，不使用资料源列表或新增一套账号。未配置时仅本地保存；配置后进入专题、投票或点击同步状态按钮触发同步。失败保留本地数据与已缓存票数，最多自动重试两次（3 秒、10 秒），仍可手动重试；下次打开再次同步。
- 云端目录为 `apps/board_game_agent/votes/national-day-2026/`，每个安装实例写自己的 `<deviceId>.json`。完整投票集合覆盖自身文件，重试不会重复加票，空集合表示全部取消。汇总其他设备的文件后加上自己的本地投票，避免共享计数文件被并发覆盖。活动 ID 固定为 2026 国庆，未来活动应使用新 ID。
- 使用现有共享 `webdav_storage` 客户端的目录枚举、上传、下载和关闭能力，单请求 6 秒、整轮 25 秒上限；最多枚举 1000 个投票文件、每批 8 个下载、单票文件 64 KiB / 256 款游戏。数据格式或文件身份异常视为同步失败，不以不完整数据覆盖缓存。缓存按 WebDAV 地址与账号隔离。
- Web 与现有 WebDAV 设置使用同源 `/webdav-proxy`；部署需保留该代理及写入、目录枚举权限。没有代理、网络、写权限或有效鉴权时保留本地投票。当前不连接真实 WebDAV 做验证。
- 这里按安装实例计票，不是登录用户：同一人使用不同设备可分别投票，清除本地存储会生成新实例；如需严格“一人一票”需要账号或服务端身份校验。Web 本地缓存按站点 origin 隔离（不同端口或 localhost / 127.0.0.1 是不同实例）。
- Windows 专题页保留窗口拖动、调整大小及最小化、最大化、关闭；Web 使用同一页面。

桌面主界面位于 `lib/ui/desktop/national_day_page.dart`；手机主界面位于 `lib/ui/mobile/national_day_screen.dart`，标题与卡片拆在同 library 的 artwork / cards 文件。两端从首页第二张国庆横幅进入，手机支持滑动及点击轮播指示点；返回保留首页位置。手机封面进入现有游戏详情页，返回详情后仍是专题页。手机顶部提供同步与复制分享，沿用桌面端去掉顶部收藏的设计。点赞票数及橙色选中边框对应真实投票状态。

验收覆盖参考尺寸、标准及大桌面尺寸、125% 字体、添加与移除、空清单重开、保存失败、复制分享、投票 / 取消且不改变收藏、打开游戏详情；服务测试覆盖本地重启、多设备汇总、幂等同步、离线缓存与取消、同步期间修改、账号隔离、失败重试和 WebDAV 模拟传输。测试渲染截图用于构图核对，不代表原生 Windows 渲染验证。

手机验收覆盖 320×640（125% 字体）、390×844、430×932、844×390，以及两端共用清单、投票重启恢复、添加搜索、空清单、读取/保存失败、分享和详情返回。截图使用实际字体和资源的 Flutter 测试渲染，不代表真机截图。真实 WebDAV 联通验证遵循用户要求暂不执行；部署仍需可用的 WebDAV 与 Web 代理。回滚时可还原这次界面与共享清单改动，本地缓存键和投票格式兼容原桌面版。
