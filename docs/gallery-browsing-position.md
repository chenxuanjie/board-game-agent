# 桌游详情图片位置

Windows 与宽屏 Web 的桌游详情按当前账号、桌游 slug 记录上次选中的图片。点击缩略图或使用键盘切换图片时立即记忆；离开并重新进入详情、退出后再次登录，以及程序重启后恢复。

保存图片的资源路径，而不是固定的数组下标。图片重新排序时仍恢复同一张；没有记录或记录的图片已被移除时显示第一张。当前桌面图片列表仍按横幅、图库、封面的顺序去重，不改变现有图片比例与布局。

本功能默认是本机浏览偏好：`PreferencesService` 使用 `game_gallery_selections_v1` JSON 字典，值为 `slug → 图片路径`，沿用 `personal_v1.<账号存储标识>.` 前缀隔离账号。访客使用独立的旧式无前缀键，不把访客记录复制给登录账号。记录不进入私人云同步日志或公共统计，选择图片不触发账号云同步。

写入在当前账号的不可变偏好服务中串行合并，避免快速切换图片或不同桌游丢失记录；账号切换会等待在途个人写入、清空内存选择并恢复目标账号记录。当前视图即时响应；保存失败显示简短提示与重试，内存选择保留，重启后只能恢复最近成功保存的位置。损坏的本机记录回到默认位置，不阻止启动。

主要入口：

- [位置状态与恢复](../lib/app/state/app_controller/gallery.dart)
- [按账号的本机偏好存储](../lib/features/settings/services/preferences_service.dart)
- [桌面详情图片选择](../lib/ui/desktop/game_detail_pane.dart)
