# 桌游评论

桌面详情页在“相关游戏”之后显示独立评论区；App 同样在“相关游戏”之后显示评论预览，完整列表与回复分别进入共用页面，底部提供写评论/回复入口。`GameCommentsPanel`、`GameCommentsPage` 共用模型、状态和操作，沿用项目主题。Web 当前不支持 NAS 登录，仅显示原生端登录提示，不展示虚构评论。

## 功能与规则

- 登录后读取、发布文字评论（最多 1000 字）、回复、点赞/取消点赞、删除自己的评论。支持普通文字和系统 Emoji，不解析 HTML。
- 仅主评论可附带 1～10 分整数评分，输入框下方使用五颗星，每颗星 2 分、半颗星 1 分；默认不选，再点同一评分位置可取消。支持键盘逐分调整及清除。每个 UID 对同一桌游只有一份当前有效评分；不带评分的新评论不改变旧评分。
- 每条评论显示发表时附带的评分，后台当前有效评分规则保留；评论区不再展示“桌友评分 / 暂无评分 / 人数”汇总行，也不改变游戏原有资料评分。
- 发布仅在发布按钮内显示转圈，不显示评论区顶部进度条；正常发送不插入等待发送提示，失败仍保留原因与重试。首次空列表加载使用简短文字，已有列表刷新时保留内容。
- 删除当前评分对应评论时取消该评分，不恢复更早的评分；删除旧评论不影响新评分。
- 有回复的评论删除后显示“评论已删除”，已有回复保留。不能再回复已删除原文，可继续回复保留的讨论。
- 默认热门按点赞数降序、同赞数按发布时间降序；最新按时间降序。回复按时间升序。列表每次展示 20 条，回复预览最多 2 条，App 详情预览最多 3 条。分页为本地已同步数据的显示分页。

## NAS 目录与身份

评论采用独立 app namespace `board_game_agent_comments`，目录为 `/<共享目录>/apps/board_game_agent_comments/public/v1/u<UID>/d<设备ID>.json`。不改变 `board_game_agent/public/v1` 的收藏/想玩快照协议，也不共用其同步状态。旧客户端继续读取原统计目录。

管理员在 App 外准备 `apps/board_game_agent_comments/public/v1`，沿用共享目录既有权限。本次交付的目录准备只创建这条固定目录链；不修改权限、移动/删除目录或创建其他账号数据。App 复用 `app_identity.AccountPublicFiles` 的 FileStation 身份绑定、超时、取消、DSM 所有者核验、写后回读及受控初始化，只可创建当前账号自己的 `u<UID>`；上传明确 `create_parents=false`，目录创建 `force_parent=false`。

公开记录包含作者昵称、评论正文、发表时间与可选评分；这些内容提交后供其他已登录账号阅读。评论头像复用现有默认头像，没有头像上传功能。

每个设备只替换自己的快照，快照记录追加事件，版本 1，包含 `uid`、`device`、`operations`。事件有唯一随机 ID、UID、游戏 slug、Lamport revision、UTC 时间和 `publish/delete/like` 类型；回复保存根评论和直接回复目标。删除是记录标记，不删除 NAS 文件。点赞按 UID 与评论 ID 的最新事件汇总，避免直接覆盖全局计数。其他账号的删除事件不能删除不属于该 UID 的评论；伪造 UID、文件所有者不符或同 ID 内容不一致会停止本轮读取并保留已有数据。

## 持久化与失败恢复

`GameCommentsService` 由 AccountService 按 NAS 环境及账号作用域管理，账号切换/退出销毁旧服务并取消请求。本机日志、待发送标记、设备 ID、草稿分别按账号隔离；草稿再按游戏与回复目标隔离。没有额外私人日志重复写入路径。

发布先保存本机事件与草稿 ID，再读取远端、写入自己的快照并回读核对，随后重新汇总远端。输入框在失败时保留内容，已进入队列的评论沿用同一 ID 重试，成功后清理草稿。上传确认成功而后续刷新失败时，已发送标记保留，不把它重新当作发送失败。

同一安装的多个程序实例可能共用设备文件；每轮远端读取同时核对本机已确认事件是否仍在自己文件中，缺失事件重新进入待发送队列，与远端已出现事件合并后回写。晚到的旧快照不会永久吞掉已经确认的评论。

打开评论区、手动刷新和完成操作后读取最新数据；不增加常驻全库轮询。单轮请求总预算 2 分钟，账号切换、退出或超时取消过期结果。待发送失败最多自动重试 3 次，间隔 3/6/12 秒，之后保留手动重试入口；下次打开会继续处理本机队列。单设备快照上限 512 KiB、每账号 128 个设备、单次最多 1000 个账号/2000 个快照/20000 个事件。这是现有 NAS 账号之间的轻量评论方案，不是公开注册社区的服务端分页/审核系统。

## 验证与回滚

回归覆盖可选评分、同账号跨设备计分/点赞、并发账号写入、取消点赞、删除与回复保留、越权/伪造身份、上传确认丢失、进程重建后重试、草稿隔离、账号切换、无登录入口以及窄屏/桌面/大字号主题布局。实际 NAS 评论发布、Android 安装与 Windows 安装验收需分别记录，内存传输测试不能替代实机验证。
