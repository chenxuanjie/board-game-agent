# 内容界面的共同设计规则

首页与相关游戏通过 `ContentCardStrip`、`ContentCardSurface` 和
`GameContentCard` 共享视觉规则；最近浏览使用简洁的封面列表。
按内容用途选择布局，统一主题、字号层级和交互，不强求所有卡片同高。业务状态仍由 AppController 管理。

## 紧凑卡片

- 横向卡片宽限制在 240–280 dp；较宽内容区按完整卡片计算数量。
- 推荐卡按内容宽尝试容纳两张卡，基准高度 154 dp；实际属性换行或系统字号放大时自动增高，同一列表等高。
- 卡片圆角 16，间距 12；推荐卡左图占宽度约 40%（96–112 dp），使用 cover 贴合卡片上下边缘，由卡片统一裁切圆角。完整盒面查看交给详情页。
- 标题 15 / w700 / 1.2，评分 14 / w700 / 1.2；推荐卡辅助文字与简介 11 / w400 / 1.3。
- 属性最多两个，完整换行；简介最多三行，与评分间隔 22 dp。
- AI 对话与相关游戏基准高度 168 dp，辅助文字 12；相关游戏左图占 38%，使用 contain 完整展示图片。
- 最近浏览只展示封面、名称与时间，封面宽 88–112 dp、比例 77:88，统一圆角 12；名称 13、时间 12，不重复评分与属性。
- 触控使用滑动；Web、桌面使用已有的悬停/聚焦滚动条，支持拖动。

## 其他页面

- 游戏库采用 3:4 的封面展示框，完整显示原图；卡片依次展示名称、属性、评分、人数与时长。最多两个属性以浅橙底、橙字标签显示；夜间使用主题容器颜色，长标签和大字号可换行。
- 游戏库卡片的信息区使用 TextPainter 测量，不以固定高度挤压长人数说明和放大后的文字。
- 颜色来自 AppPalette；功能图标使用圆角 Material 图标，品牌和节日插画保留独立表现。
- 卡片、分组、普通控件的圆角分别为 16、20、12，由 UiTokens 管理。
- 详情底部操作在窄宽度或大字体下上下排列，保留原有规则书与 AI 助手入口。
- 消息通知“活动、评论、系统消息等”、设置“语言、偏好设置”继续保留。

## 验收与回滚

- 回归检查 320、390、430、720 dp，100%、125%、200% 字号及暖色、夜间主题。
- 检查推荐图片贴边、三行简介、最近浏览封面尺寸一致、彩色标签换行、详情跳转和独立的喜欢按钮。
- 本次仅调整展示组件与主题，不改变 AI 请求、推荐算法、资料或同步协议。
- 原生布局由 widget 测试验证；Web 使用 release 构建。测试渲染图不代替 Android 实机或 Windows 原生截图。
