# AI 助手功能审查（2026-10-02）

## 本次已修复

| 问题 | 修改和验收 |
| --- | --- |
| 模型弹层保留整块空白，设置与列表对齐不一致 | 移除猜测的固定高度，以内容决定高度，最大 430 dp；短窗口或大字体允许滚动；没有可配置模型时不显示无关设置，空状态也按提示文字收缩。单模型测试要求列表剩余空白小于 20 dp、弹层高度小于 360 dp；未配置状态在 320/1280 宽均小于 180 dp。 |
| 历史会话没有删除入口 | 历史抽屉每条会话增加删除图标、确认、进行中和失败反馈。删除最后一条时创建独立的空会话。取消不修改数据；保存失败保留原会话，允许重试。 |
| 删除与生成、草稿缓存可能相互干扰 | 删除使原 Run 失效并清理服务上下文；持久化成功后才移除会话、Run 展开状态及界面草稿和滚动缓存。迟到增量不能写入新会话。确认删除后即停止旧生成；若保存失败，原会话和已收到内容仍保留。 |
| 模型配置保存失败时内存已切换 | 串行保存配置；主配置持久化成功后才发布到界面与服务。失败保留当前选择，下一次保存可重试。供应商预设历史是独立的次要保存，不把其失败误报为主配置失败。 |
| 偏好写入返回 false 没有报错 | 模型配置、桌游回答模式和通用回答模式检查存储返回值，失败走现有重试反馈。 |
| 桌面回答缺少复制，部分语音按钮点了无反应 | 桌面增加复制与成功/失败反馈；紧凑界面复制补充失败处理；语音服务不可用时隐藏朗读操作。 |

测试覆盖：当前/非当前/最后一个会话删除、取消、写入失败和重试、重启恢复、生成中删除与迟到事件隔离、删除后草稿清理、复制回答、不可用朗读、单模型高度、配置写入失败与重试。桌面和紧凑布局的删除操作覆盖 125% 字体。

## 已有能力与实际边界

- 模型发现、筛选、能力目录、适用推理强度、标准/快速及刷新失败重试已有实现。目录不能证明中转服务实际执行了所选模型或参数，本次没有向真实供应商发起请求。
- 新会话、历史切换、通用/桌游范围、页面内草稿与滚动恢复已有实现。
- 发送、停止、流式增量、真实 Run 阶段、部分答案、失败原因和尝试次数、失败重试、引用展示与迟到 Run 隔离已有实现。本次保留这些状态边界。
- 中文/English、键盘、减少动画、窄窗口和大字体已有回归用例。自动化组件测试不等于原生三端性能验证。

## 仍未完成的缺口

以下是实际代码路径中的问题，不应把本次 UI 修复描述为已经完成全部 AI 产品能力。

| 优先级 | 缺口 | 建议 |
| --- | --- | --- |
| P1 | `conversations.dart` 的 `_maxMessagesPerConversation = 100` 与 `_trimConversationMessages` 直接裁剪会话消息并保存。超过上限的历史不是单纯退出请求上下文，而是从本地历史中移除。 | 分开持久化聊天历史和有界的模型请求上下文；历史分页加载。需要存储版本迁移、崩溃恢复与长对话测试，不能简单放开内存上限。 |
| P1 | 普通聊天快照保存失败通常仅记录日志，用户可能不知道当前内容没有保存。创建和本次删除会传播错误，普通生成保存仍缺少可见状态。 | 在共享会话状态中增加保存中/已保存/失败及重试，并验证磁盘不足、关闭程序、写入中断。 |
| P1 | 通用会话的知识库模式没有完整的资料绑定入口。模式开关不等于选择了资料；桌游会话可沿用绑定的规则，通用会话不能自动取一个无关桌游。 | 在知识库模式内按需选择桌游或已导入文档，明确显示绑定范围并持久化。没有资料时提供选择入口。 |
| P2 | 历史缺少搜索、手动重命名、导出和备份；标题主要依赖首条问题。 | 优先增加搜索和重命名，再做导出/备份。删除不替代历史管理。 |
| P2 | 成功回答缺少重新生成与编辑问题后重新发送；已有失败重试。 | 保存答案版本和关联请求，避免重试覆盖已确认的答案与引用。 |
| P2 | 草稿主要依赖页面状态，退出程序后不保证恢复；模型为空的提示缺少直达 AI 配置的操作。 | 持久化轻量草稿；从空模型状态直接进入配置并返回原草稿。 |
| P2 | 主配置成功后，供应商预设历史写入失败仅有日志。 | 独立记录预设保存失败和重试，保持主配置成功语义。 |
| P2 | 老配置仍可能存有已隐藏的“自动/无”推理强度；这时可选按钮没有选中项，实际请求继续沿用老配置。 | 增加明确的迁移策略或按需提示用户选择。不能仅为了显示选中态而假称实际发送了另一个参数。 |

建议先解决前三项，再扩展历史管理；本次没有改动消息存储结构或引入新的 Agent/RAG 实现。
