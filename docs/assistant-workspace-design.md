# AI 助手界面

本次实现对应用户确认的 AI 助手视觉预览，代码基线为 `647c587`，分支为 `codex/ai-workspace-polish`。工作在独立 Git worktree 中完成；原工作区的分支、未提交文件、运行实例和 `8081` Web 服务不参与本次修改。

## 界面与操作

- 桌面消息区与输入区共用居中的阅读宽度，空会话使用简短欢迎标题及三个快捷问题。只有启用当前桌游资料时显示游戏名称。
- 快捷问题填入草稿并聚焦，用户确认后发送。缺少模型时保留草稿并提示选择模型。
- 输入框下方左侧为回答模式，右侧只显示模型名与发送操作；模型使用主题字体 14 / 500，不在概要中重复强度。窄窗口和放大字体时重排，避免压缩文本。Enter 发送，Shift+Enter 换行，输入法组合输入时不截获 Enter。
- 模型弹层复用现有 `/models` 获取、白名单及模型能力目录；模型、该模型适用的推理强度、标准/快速服务等级集中显示。界面隐藏“自动”和“无”，沿用现有配置归一化及请求映射，不宣称中转站实际执行了指定强度。
- 点击会话标题打开历史抽屉，标题箭头随开合变化；页头新增新会话按钮。创建失败保留当前会话并提示重试，成功后切换到新的独立草稿。抽屉原有分类、切换、删除及保存错误状态继续使用。
- 语音转文字保留麦克风入口；紧凑界面的会话菜单保留语音模式、上下文及清空操作。实时语音尚未配置时仍显示真实不可用原因。
- 真实 Run 阶段、部分答案、失败原因、重试、引用及停止生成使用原来的控制器和展示组件。

## 代码边界

`lib/ui/shared/assistant/assistant_presentation.dart` 提供欢迎区和输入框；`model_selector.dart` 从桌面目录迁入共享目录，桌面、窄屏 Web、Android 使用同一套选择逻辑。`assistant_motion.dart` 仅处理展示过渡，不创建新的请求状态或延迟网络调用。桌面和紧凑页面继续持有草稿、滚动位置及各自布局。

所有组件继承已有主题与打包字体，没有引入图片替代控件、新字体或动画依赖。首次进入历史消息及会话切换不重播消息入场；真实新增消息只做一次淡入/轻移，流式增量立即更新。减少动画设置将展示动画时长归零。

## 回答模式与输入工具区简化

桌面页头删除含义不明确的更多菜单以及对应的旧上下文面板，标题仍打开历史，新建图标仍创建会话。回答模式由共享 `answer_mode_selector.dart` 提供，弹层只有“知识库”和“智能补充”：前者沿用仅知识库回答，后者沿用知识库优先、允许智能补充的已有业务模式。弹层没有资料、上下文或权限等无关条目。模式保存时显示进度并禁止重复选择；保存异常恢复原模式、提示重试，通用和桌游模式仍独立保存。

输入区右侧只显示模型名，统一继承打包字体并使用 14 / 500；推理强度及标准/快速仍能在模型面板中设置，隐藏概要文字不改变请求配置。中文和 English 切换沿用本工程文案体系。

本次直接复用 Flutter 3.41.9 [`PopupMenuButton`](https://api.flutter.dev/flutter/material/PopupMenuButton-class.html) 及 `packages/flutter/lib/src/material/popup_menu.dart` 的定位、键盘/焦点和点击外部收起行为；覆写选项容器仅用于裁剪圆角，不复制弹层管理器。动画采用已有 AppMotion 的 180 / 140 ms，遵循系统减少动画。SDK 属于现有 BSD-3-Clause 依赖，没有新增许可证或服务依赖。升级 Flutter 时回归菜单定位、键盘、125% 字体和保存异常。

新增验收：桌面页头无更多菜单；概要模型字体与强度隐藏；320 / 736 / 1280 宽、125% 字体的菜单边界；Esc 和点击外部收起；实际偏好保存、重复选择禁止、失败回滚和重试；通用模式不会改写桌游模式。

本次最终静态检查无问题，全工程 270 项测试通过。Windows x64 和 Web JavaScript Release 已重新构建（2.1.0+22）；浏览器实际检查了 1100 × 800 / 1280 × 800 的桌面菜单，以及紧凑布局，独立预览使用 8084。截图与验收不代表真实 AI 服务调用或原生 Windows/Android 帧率测试。知识库模式仍使用当前会话绑定的资料边界；通用会话未绑定资料时，原工作流继续报告知识库不可用，不会把模型生成内容标为知识库证据。
