# AI 助手界面

本次实现对应用户确认的 AI 助手视觉预览，代码基线为 `647c587`，分支为 `codex/ai-workspace-polish`。工作在独立 Git worktree 中完成；原工作区的分支、未提交文件、运行实例和 `8081` Web 服务不参与本次修改。

## 界面与操作

- 桌面消息区与输入区共用居中的阅读宽度，空会话使用简短欢迎标题及三个快捷问题。只有启用当前桌游资料时显示游戏名称。
- 快捷问题填入草稿并聚焦，用户确认后发送。缺少模型时保留草稿并提示选择模型。
- 输入框将智能补充、模型/推理强度与发送收在下方工具行；窄窗口和放大字体时重排，避免压缩文本。Enter 发送，Shift+Enter 换行，输入法组合输入时不截获 Enter。
- 模型弹层复用现有 `/models` 获取、白名单及模型能力目录；模型、该模型适用的推理强度、标准/快速服务等级集中显示。界面隐藏“自动”和“无”，沿用现有配置归一化及请求映射，不宣称中转站实际执行了指定强度。
- 点击会话标题打开历史抽屉，标题箭头随开合变化；页头新增新会话按钮。创建失败保留当前会话并提示重试，成功后切换到新的独立草稿。抽屉原有分类、切换、删除及保存错误状态继续使用。
- 语音转文字保留麦克风入口；紧凑界面的会话菜单保留语音模式、上下文及清空操作。实时语音尚未配置时仍显示真实不可用原因。
- 真实 Run 阶段、部分答案、失败原因、重试、引用及停止生成使用原来的控制器和展示组件。

## 代码边界

`lib/ui/shared/assistant/assistant_presentation.dart` 提供欢迎区和输入框；`model_selector.dart` 从桌面目录迁入共享目录，桌面、窄屏 Web、Android 使用同一套选择逻辑。`assistant_motion.dart` 仅处理展示过渡，不创建新的请求状态或延迟网络调用。桌面和紧凑页面继续持有草稿、滚动位置及各自布局。

所有组件继承已有主题与打包字体，没有引入图片替代控件、新字体或动画依赖。首次进入历史消息及会话切换不重播消息入场；真实新增消息只做一次淡入/轻移，流式增量立即更新。减少动画设置将展示动画时长归零。

## 参考与复用

- [Open WebUI v0.11.0 MessageInput.svelte](https://github.com/open-webui/open-webui/blob/v0.11.0/src/lib/components/chat/MessageInput.svelte)：参考统一输入工具区及请求中控件反馈。其实现使用 Svelte/TypeScript，不能作为 Flutter/Dart 控件直接引入。本次没有复制源代码或引入其依赖；发送、取消、语音和持久化复用本工程现有代码。
- [Fluent 2 motion](https://fluent2.microsoft.design/motion)：参考短距离、用途明确、快速收敛和减少动画原则。
- [Flutter 性能实践](https://docs.flutter.dev/perf/best-practices)：使用隐式动画和现有组件，避免对聊天列表整体做重复过渡或模拟打字速度。

本次属于 UI 交互调整，没有变更 AI 协议、Agent 编排、重试策略或知识库处理，没有新增外部依赖、复制代码或改变许可证要求。
