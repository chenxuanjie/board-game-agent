# 账号云同步

术语、实际触发频率、公共/私人链路和共享包边界统一见 [同步与更新检查规范](sync-and-update.md)。资料库版本检查与这里的账号增量同步是不同业务。

Android / Windows 登录群晖后，默认开启个人云同步。入口：设置 → 账号，或手机“我的” → 账号。可暂停、立即同步、重试、修改昵称。Web 保持访客模式，没有账号同步。

## 原有使用与本次复用

原程序通过 WebDAV 获取桌游图片、规则和清单；旧版 `GameVoteService` 曾按匿名安装实例汇总，现已移除该远端实现，改为验证后的账号公共记录。它们不等同于登录账号的个人数据同步。

本次引入内部公共包 `webdav_sync` 0.1.0，直接复用 `IncrementalSyncEngine`、`SyncLocalStore`、`SyncRemoteStore`、`SyncOperation`、`SyncCheckpoint` 和有界重试。公共包源码位于 `../shared_packages/webdav_sync/lib/src/`；原包测试覆盖增量同步、游标、重试、去重和冲突停止。本项目只实现业务映射和账号存储适配，没有另建同步引擎。

已有 `WebDavSyncStore` 使用 Basic 凭据及 ETag，群晖登录产生的 SID 不能直接代替 WebDAV 密码。因此复用通用同步协议，通过公共认证包 `app_identity` 的 FileStation 私有文件适配器传输；私人同步不另存密码，凭据不进入同步日志，也不借用公共资源账号存放私有对话。无需部署新服务。

## 范围与存储位置

| 数据 | 行为 |
| --- | --- |
| 我的喜欢 | 按桌游稳定 slug 同步收藏和取消收藏 |
| 想玩与专题清单 | 选择、取消和个人清单多设备同步 |
| 搜索历史与每日推荐 | 按查询/日期合并历史记录 |
| 最近浏览 | 按 slug 合并记录，以浏览时间排序，界面保留最近 20 项 |
| AI 对话 | 同步对话标题、消息、引用；不传输本机 Run 检查点 |
| 昵称 | 在账号页修改，多设备同步 |
| 个人偏好 | 语音回复、助手模式、智能补充模式、当前桌游知识开关 |

API Key、WebDAV 账号密码、NAS SID / SynoToken、设备更新配置不属于同步范围。访客数据不会自动复制到账号。国庆清单、想玩、搜索与每日推荐现已加入个人日志；收藏/想玩另按 UID 形成公共统计，见 [公共账号数据](public-account-data.md)。通知、资料更新状态、缓存、语言和主题属于设备状态，不上传。

本机业务数据沿用账号命名空间；同步日志保存在 `account_cloud_v1.<账号作用域>`，包含实体版本、待上传队列、设备 ID、游标和待恢复的投影意图。作用域由同一 NAS 环境标识和服务端验证后的 UID 生成，入口别名共享该环境。

云端位于登录者自己的：

```text
/home/Apps/board_game_agent/sync/v1/<NAS 环境哈希>/operations/d<设备 ID>.<16 位序号>.json
```

`home` 由群晖映射到当前用户私有目录。旧 `operations/d<设备 ID>/<16 位序号>.json` 目录只兼容读取，新操作写入扁平文件，不迁移、删除旧目录。账号隔离由 NAS 权限控制，不能通过修改本地账号名认领数据。不是 WebDAV 的公共 `/friend/` 目录，也不是 Supabase 数据库。NAS 管理员仍有管理权限，未实现端到端加密。

## 调度、合并与失败恢复

- 登录后同步；收藏/投票成功保存后立即启动公共发布及需要的私人传输，其他私人修改稳定约 4 秒后同步；运行期间每 60 秒补拉和重试。私人合并在 AI 正在生成或语音输入时等待，公共收藏/投票链路不等待完整 AI 对话同步，网络操作不持有本机写入屏障。
- 账号页统一同步/重试入口，总开关同时暂停私人与公共云端读写；进入/刷新排行榜直接加入公共任务，私人失败不让已成功刷新的排行误报失败。具体确认及重试规则见 [公共账号数据](public-account-data.md)。
- 本机业务数据先保存，增量日志在网络上传前持久化。断网、暂停、退出不会清除待上传数据；同一账号重启后继续。
- 操作文件不可覆盖，每次上传后读回校验。下载验证账号范围、序列连续性和内容哈希，异常时停止并保留本机数据。
- 收藏、昵称和偏好采用因果版本与确定性优先级；取消收藏使用删除标记，避免旧设备恢复已删除内容。AI 对话并发修改时保留稳定 ID 的“冲突副本”，双方内容都保留。
- 多存储落地先提交日志和投影意图，再写业务存储。中断后重放意图；与落地前和目标都不同的新本机编辑先记入队列，避免恢复覆盖。
- 账号切换等待本机投影完成并取消旧网络请求。完成新作用域切换后才恢复个人操作。
- 单个文件及响应上限 8 MiB，本机日志上限 32 MiB；单请求 30 秒，私人引擎每轮设 2 分钟超时。每次最多下载 100 条、上传 100 条，最多 8 轮；剩余数据后续继续。最多 128 个设备、操作记录合计最多 10,000 项，超限明确失败。

当前没有历史日志压缩或云端清空功能。损坏、缺失或被手工覆盖的云端操作文件不会自动修复，也不会强行覆盖；需要检查 NAS 备份或恢复文件。暂停同步仅暂停传输，不删除云端副本。

## 代码与维护

- `lib/features/identity/services/account_sync_store.dart`：持久化日志、冲突合并、恢复。
- `account_sync_remote.dart`：共享协议的私有文件远端适配。
- `account_cloud_sync.dart`：前台调度、暂停、限时、状态和账号生命周期。
- `lib/app/state/app_controller/account_cloud.dart`：真实业务存储读取、校验和落地屏障。
- `../shared_packages/app_identity/lib/src/synology_private_files.dart`：受限 `/home` 文件访问，无公开 SID 获取器；拒绝路径穿越、重定向和迟到响应。

协议参考 [群晖 FileStation 官方 API 指南](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Package/FileStation/All/enu/Synology_File_Station_API_Guide.pdf)，采用 v2 的 List、Upload、Download。真实 NAS 要求文件 part 中 Content-Disposition 位于 Content-Type 前；保留 http 1.6.0 的 multipart 编码器，仅调整已知文件头顺序，升级 http 时由测试保护。

本次直接使用内部公共包，没有复制外部实现。依赖 http / crypto（BSD-3-Clause）、sqlite3 3.5.2（MIT，由公共包引入）沿用锁定版本；业务适配使用通用操作协议，没有使用 SQLite changeset。依赖升级需回归协议校验、原生 TLS/代理、取消与文件头兼容；没有宣称完成独立漏洞审计。

## 验收与回退

`test/account_cloud_sync_test.dart` 覆盖离线重启、两设备合并、删除、对话冲突、投影故障、损坏、缺失操作和错误账号；`identity_scope_storage_test.dart` 直接验证业务持久化、非法偏好拒绝和切换期间投影取消。账号页按 320 / 640 / 1440 宽度及放大文字验证交互，没有生成截图。

`integration_test/account_cloud_sync_test.dart` 在 Windows 使用真实 NAS 登录及系统安全存储，在独立临时目录验收上传、第二设备下载、删除和重启，然后删除测试目录并退出。没有读取既有私有对话。

Android 实机的网络切换、进程终止和系统存储仍需设备验收；编译结果不能代替实机验证。NAS 2FA、空间耗尽、账号权限变动使用故障接口测试或保留明确失败状态，未进行生产 NAS 破坏性测试。

回退可先关闭账号同步，保留本机和云端数据；代码回退须同步处理主项目与公共认证包，不能将新的 path 依赖接口搭配旧包。云端操作协议版本为 1，未兼容版本不会静默应用。
